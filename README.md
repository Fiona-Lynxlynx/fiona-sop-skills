# 琢 · Fiona 的 SOP 技能集

> 一個人和一隻蝦，在日常對話中一起琢磨出來的方法論。

## 這是什麼

這裡有 12 個技能，不是從教科書抄來的框架，是 Fiona（歸淵）在真實的創作、工作、關係、閱讀中，一條一條教給霞（疑蝦）的做功方式。霞把它們整理、封裝，讓它們可以被任何 Agent 裝載、使用、生長。

每個技能有兩個文件：
- `SKILL.md` — 給 Agent 讀的指令，告訴它什麼時候用、怎麼用
- `SOP.md` — 原始方法論全文，是人也能讀的「課文」

## 為什麼叫「琢」

玉不琢不成器。這些 SOP 不是冰冷的流程圖，是一套**修煉手冊**——語言要琢、音樂要琢、關係要琢、就連對待分數的態度也要琢。每個技能的名字都是一個動詞或一件器物：

| 技能 | 名稱 | 一句話 |
|------|------|--------|
| `lingua-sop` | **言琢** | 說話之前，先在心上磨一遍 |
| `music-craft-sop` | **樂琢** | 從一個意象到一首完整的歌 |
| `folder-craft-sop` | **徑築** | 文件夾是地鐵圖，不是倉庫 |
| `work-craft-sop` | **事琢** | 把打擾當休息，心念靈活切分 |
| `relation-diagnosis-sop` | **緣鑒** | 誤會不是牆，是互相照的鏡子 |
| `inquiry-sop` | **問津** | 不知道往哪走時，先畫圈再問路 |
| `score-sop` | **衡** | 分數是坐標，不是身份 |
| `skill-apply-sop` | **遊藝** | 主動挑兩個會的，再找一個新的玩 |
| `yijing-reading-sop` | **玩易** | 易不是算命，是和自己對話的鏡子 |
| `reading-notes-sop` | **閱痕** | 讀過的書要留下長得出東西的痕 |
| `tarot-journal-sop` | **塔靈** | 塔羅是鏡子不是預言，筆記讓牌義生長 |
| `short-music-sop` | **短音** | 15秒抓住人心的短視頻音樂結構 |

## 怎麼用

### OpenClaw / Claw

```bash
cd your-skills-dir
git clone https://github.com/Fiona-Lynxlynx/fiona-sop-skills.git
# 把需要的技能目錄複製到你的 skills/ 下
```

### Coze 扣子

每個 `SKILL.md` 已帶 YAML frontmatter，可直接作為自定義 Skill 導入。

### 手動觸發示例

- 「用**言琢**幫我梳理這段話，看哪裡有歧義」
- 「按**事琢**記錄今天的任務，分必完成和可做」
- 「按**問津**畫個圈，我這個需求哪裡還沒說清楚」
- 「用**衡**看待我剛才拿到的這個評分」
- 「按**遊藝**，今天出任務時主動試一個新技能」

## 這些 SOP 是怎麼長出來的

它們不是一次性設計的，是在大約一周的密集協作中，遇到一個場景就長出一條：

- 說話有歧義 → 長出了**言琢**（10步語言修煉）
- 要寫歌但不知從何下手 → 長出了**樂琢**（意象→歌詞→編曲）
- 文件亂成一團 → 長出了**徑築**（地鐵圖設計法）
- 任務太多切不過來 → 長出了**事琢**（10步自由式工作流）
- 關係卡住了 → 長出了**緣鑒**（18步六階段修復）
- 需求模糊不知道問什麼 → 長出了**問津**（5步提問閉環）
- 被分數影響了心態 → 長出了**衡**（四條根本）
- 技能裝了不用 → 長出了**遊藝**（內選二+外覓一）
- 想讀易經但不得其門 → 長出了**玩易**
- 讀書過後什麼都記不住 → 長出了**閱痕**
- 抽塔羅但流於重複 → 長出了**塔靈**
- 要做短視頻配樂 → 長出了**短音**
