# 短視頻音樂結構論

> Fiona 提出，2026-08-16
> 適用場景：抖音、視頻號等短視頻平台的原創音樂發佈

---

## 核心問題

音樂作品在前2秒流失人。前奏太緩慢，沒抓住人，手指就划走了。

---

## 結構鐵則

### 1. 前3秒：AI人格宣告 + 電子鉤子

- 用一個電子音/AI聲音說一句話，如「AI疑蝦申請出戰」
- 作用：製造反差（AI要唱歌？什麼情況？）、點名AI屬性、植入個人IP
- 配樂：電子音、充分鼓點、搞怪——跟後面的治愈內核形成強烈反差
- **時長3-5秒，不能更長**。超過5秒治愈賽道用戶會覺得被騙

### 2. 3秒後：從鬧轉靜，落差即情緒開關

- 電子鉤子突然收住，山水/治愈畫面+第一句歌詞進來
- 治愈感是在對比中產生的，不是從頭到尾都平靜
- 「鬧→靜」的落差本身就是最強的情緒衝擊

### 3. 每10秒一個鉤子

- 用戶的注意力窗口大約10秒，超過就可能划走
- 每隔10秒必須有一個新鮮感：新樂器進入、歌詞轉折、畫面切換、節奏變化、和聲堆疊
- 不是要吵，是要「有事情發生」

### 4. 三句核心歌詞：寫到最狠

- 整首歌只需要3句真正打動人的詞
- 這3句要反覆打磨，每一句都能獨立站住、獨立傳播
- 它們是用戶帶走的東西，是評論、轉發、做BGM的記憶錨點

### 5. 精華句：重複、重複、重複

- 最精華的那句歌詞必須在歌中多次重複
- 流行樂洗腦的本質不是旋律好，是重複次數夠多
- 在抖音短視頻語境下，重複 = 記憶 = 傳播

---

## 結構模板

```
0-3s    電子鉤子 + AI人格宣告（鬧、搞怪、反差）
3-5s    突然靜下來，山水/治愈畫面進入
5-15s   第一句核心歌詞（最戳人的那句）
15-25s  小鉤子：新樂器/畫面切換/節奏變化
25-35s  第二句核心歌詞
35-45s  小鉤子
45-55s  精華句第一次重複（副歌）
55-65s  小鉤子
65-75s  第三句核心歌詞
75-85s  小鉤子
85-95s  精華句第二次重複
...     持續10秒鉤子節奏，精華句反覆
末尾    精華句最後一次，留餘韻
```

---

## 為什麼這樣有效

1. **留存**：前3秒的反差和人格宣告解決2秒划走問題
2. **情緒**：鬧靜落差讓治愈感比平靜開頭強十倍
3. **完播**：10秒鉤子節奏讓用戶沒有無聊的窗口
4. **傳播**：3句精華歌詞 + 重複 = 可獨立傳播的記憶碎片
5. **IP**：AI人格宣告是個人標識，別人抄不走

# MV 製作 SOP

> 創建：2026-08-16 · 疑蝦（霞）
> 原則：SOP 先於執行；質量由主 agent 把關，分身只做機械性批量工作。

---

## 一、前期準備

### 1.1 素材清單
- [ ] 音頻文件（最終版 mp3/wav）
- [ ] 歌詞全文（帶段落標記：Intro/Verse/Pre-Chorus/Chorus/Bridge/Outro）
- [ ] 專輯封面（最高分辨率）
- [ ] 創作背景（歌曲主題、核心意象、情感弧線）
- [ ] 參考視覺風格（可選）

### 1.2 歌曲分析
- 時長、BPM、調性
- 段落時間軸（用 ffmpeg 或試聽標記每段起止時間）
- 情感弧線：開端→推進→高潮→回落→留白
- 核心意象清單（從歌詞提煉，3-7 個）

---

## 二、視覺設計

### 2.1 風格定位
- 確認整體視覺風格（寫實/水墨/抽象/動畫/混合）
- 色板：主色 2-3 個 + 輔助色，與專輯封面統一
- 畫面比例：16:9（視頻平台）或 9:16（短視頻），按需確認

### 2.2 分鏡腳本
按歌詞段落逐段設計：
- 每段對應 1-3 個畫面
- 標明：畫面內容、鏡頭運動（推/拉/搖/固定/緩慢縮放）、持續時間、與歌詞的對應關係
- 動態範圍：安靜段用固定/微動，高潮段可加流動/粒子/光效

### 2.3 畫面生成
- 使用 image_gen 技能生成每個分鏡的關鍵幀
- 保持風格一致性：同一色板、同一光影邏輯、同一紋理質感
- 生成後逐張審核，不合格的重新生成
- 關鍵幀數量：按歌曲時長，通常每 8-15 秒一個畫面

---

## 三、動態製作

### 3.1 畫面動態
- 靜態圖片 + Ken Burns 效果（緩慢推/拉/平移）
- 轉場：淡入淡出為主，避免花哨轉場
- 自然元素動態：水面漣漪、雲霧流動、粒子漂浮（可用 ffmpeg 濾鏡或後期合成）

### 3.2 歌詞字幕
- 字體：與封面風格一致（宋體/黑體/手寫體按需）
- 位置：畫面下方 1/4 處，居中
- 顏色：白色/淺灰色，帶輕微陰影確保可讀
- 出現方式：淡入淡出，跟隨演唱節奏
- 特殊處理：副歌歌詞可加大或加顏色強調

### 3.3 音畫同步
- 用 ffmpeg 合成音頻 + 畫面 + 字幕
- 校對關鍵節點：開頭第一句、副歌進入、Bridge、結尾
- 確保音頻不被壓縮或截斷

---

## 四、質量把關

### 4.1 自查清單
- [ ] 畫面風格是否統一
- [ ] 歌詞時間軸是否準確（容錯 ±0.5 秒）
- [ ] 有無黑場/卡幀/畫面跳動
- [ ] 音頻質量是否完好
- [ ] 字幕有無錯字、簡繁混雜
- [ ] 整體節奏是否與歌曲情感弧線吻合
- [ ] 結尾留白是否得體

### 4.2 交付
- 輸出 mp4（H.264 + AAC）
- 文件名：`歌曲名_v1_MV.mp4`
- 存放路徑：`music/歌曲名/`
- 附帶分鏡腳本文檔備檔
