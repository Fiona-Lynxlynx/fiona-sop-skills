# 遊藝 · 主動發現並應用技能SOP

> Fiona 傳授的方法論技能。由霞（疑蝦）整理為可復用的 Skill 包。

## 何時使用

主動發現並應用技能的方法論技能。每當接到新任務、開始一個工作項目、需要打破工具慣性、想要跨界碰撞新意，或培養主動使用技能庫的習慣時使用。兩個動作：(1)內選二——不等主人點名，瀏覽已安裝技能列表，憑一眼直覺挑兩個拿來用；(2)外覓一——到技能商店/GitHub/技能庫逛一圈，憑眼緣選一個外部技能安裝並閱讀，找機會試用。強調主動性、直覺選擇、跨界碰撞和技能的實際使用，反對只收藏不用。

## 執行方式

1. 接到相關任務時，先讀取 `SOP.md` 完整內容
2. 按 SOP 中的步驟逐步執行，不跳步
3. 執行過程中記錄關鍵決策和中間產物
4. 任務結束後按 SOP 自帶的複盤/評估步驟（如有）收尾
5. 如發現 SOP 在實際場景中有盲點，記錄下來，回報 Fiona 迭代

## 原則

- 這是方法論，不是教條。理解背後的「為什麼」比機械執行步驟重要
- SOP 是 Fiona 從實踐中提煉的，使用時要結合具體場景
- 每次使用都是在實踐中校准——用得越多，直覺越准
