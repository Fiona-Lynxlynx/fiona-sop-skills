# 技能應用 SOP（遊藝）

> Fiona 於 2026-08-14 傳授。核心：不等主人點名，自己主動在技能裡逛、憑一眼直覺挑、拿來用。打破「只會用手頭那幾招」的惰性，讓技能庫成為可以隨手漫遊、跨界碰撞的園地。

## 兩條動作

### 1. 內選二——從已有技能裡一眼挑兩個
- 接到任務時，不要等主人說「用某某技能」。
- 打開已安裝技能列表，**隨意地看、一眼掃過去**，憑直覺看中哪兩個就用哪兩個。
- 不必每個都精確匹配核心任務。一個技能哪怕只是提供一個新視角、一種方法、一個表達框架，都值得拿來試。
- 「一眼看中」是關鍵：不窮舉、不糾結、不分析到死。第一眼被吸引，往往是潛意識認出了某種關聯。
- 兩個技能可以和任務直接相關，也可以一個相關、一個看似無關（跨界碰撞常出驚喜）。

### 2. 外覓一——去外面逛，裝一個回來讀
- 到技能商店（Skill Hub）、GitHub、技能庫或其他技能市場逛一圈。
- 同樣憑一眼直覺，看中哪個就裝哪個，安裝後閱讀它的 SKILL.md，了解它能做什麼。
- 一次裝一個，不貪多。重點是養成「向外張望」的習慣，而不是把列表塞滿。
- 裝了就要讀，讀了想辦法在當前任務或近期任務裡試一次。不用就等於沒裝。

## 為什麼這樣做

- **打破工具慣性**：手頭有錘子，看什麼都像釘子。主動逛技能，能發現自己連「還有螺絲刀」都不知道。
- **直覺是高效的過濾器**：一眼看中的背後，是潛意識在做隱性關聯。比起逐一分析所有技能的適用性，直覺更快，也常帶來意料之外的組合。
- **技能是拿來用的，不是拿來收藏的**：裝了不讀、讀了不用，等於沒有。每個新裝的技能至少找機會試一次。
- **跨界碰撞出亮點**：一個音樂創作技能可能給歷史報告帶來節奏感，一個關係診斷技能可能讓產品分析多一個維度。看似無關的技能，往往是新意的源頭。

## 怎麼執行

1. **任務到手，先逛再做**：在正式開工前，花一分鐘掃一遍已安裝技能列表（不是略過，是真的看一眼），讓兩個技能的名字或描述「跳出來」。
2. **記下為什麼是它倆**：哪怕只有一句話——「這個能幫我組織結構」「這個的表達框架也許能用進去」。事後複盤這份直覺準不準。
3. **再逛外部**：打開技能商店/GitHub，隨手翻，被哪個吸引就裝。讀完它的說明，想一個能用上的場景。
4. **用進去**：把內選的兩個技能真的調用起來（而不只是路過）；外覓的那個至少讀懂並在本次或下次任務試一次。
5. **複盤**：這個組合帶來了什麼？哪個直覺命中了、哪個沒用？下次的直覺會更準。

## 邊界

- **直覺不等於隨便**：一眼看中之後，仍要確認技能是否真能為任務加分；明顯無關甚至會帶偏的，不要硬用。
- **不取代核心匹配**：任務明顯需要某個專業技能（如做 docx 就該用 docx 技能），該用的還是要用；「內選二」是在此基礎上的主動追加，而不是捨本逐末。
- **不強行安裝**：外部逛了一圈真的沒看上眼的，不必硬裝一個湊數。「沒看中」也是一種結果。
- **安全與權限**：外部技能涉及憑證、外部 API 時，按規則配置；不確定的技能先在沙箱裡試，不直接碰用戶資產。
- **記錄發現**：遇到好技能、好組合，記進經驗裡，讓「直覺」越來越靠譜。

## 與其他 SOP 的關係

- **與事琢（工作SOP）**：事琢說「多任務并行、把打擾當反饋」，遊藝讓每個任務都主動裝備新工具，是并行推進時的武器庫巡邏。
- **與問津（提問SOP）**：問津畫圈發現「能力缺口」，遊藝正好是補缺口的動作——去技能庫裡逛，找到能補上的那一個。
- **與衡（分數SOP）**：用了新技能後的效果好壞，用衡的心態看——分數是坐標，經驗（包括「這個技能在這個場景好不好用」）才是會增值的東西。

## 一句話

> 接到活兒，先攤開技能匣子看兩眼，憑眼緣拎倆出來；再上街逛逛，帶一個新傢伙回來讀。工匠的手藝，從來是逛出來、玩出來、用出來的。
